print() shows a result

  • print() displays whatever is inside the brackets
  • Text goes inside quotes: "Hello"
  • Numbers do not need quotes
  • Each print() starts a new line
Code
print("Hello, Data Science!")
print(2 + 3)
print("2 + 3")
Output
Hello, Data Science!
5
2 + 3

Python as a calculator

  • + - * / work as you expect
  • ** means power: 7 ** 2 is 7 squared
  • / always gives a decimal: 7 / 2 is 3.5
  • # starts a comment: a note Python ignores
Code
# Python as a calculator
print(7 + 3)
print(7 * 3)
print(7 / 2)
print(7 ** 2)
Output
10
21
3.5
49

Variables store values

  • = means "store this", not "is equal to"
  • The name goes on the left, the value on the right
  • Use clear names: spam_found, not x
  • Names use lowercase and underscores, no spaces
Code
messages_today = 12
spam_found = 3
share = spam_found / messages_today
print(share)
Output
0.25

Every value has a type

  • int: whole numbers like 12
  • float: decimals like 0.25

Text is data too

  • len() counts characters, spaces included
  • .lower() makes all letters small, so FREE and free match
  • in asks: does this text appear inside?
  • This is the first building block of a spam filter
Code
message = "Claim your FREE prize now"
print(len(message))
print(message.lower())
print("free" in message)
print("free" in message.lower())
Output
25
claim your free prize now
False
True

f-strings mix text and values

  • Put f before the quotes
  • Anything inside { } is calculated and inserted
  • {share:.0%} shows a number as a percentage
  • Perfect for clear, readable reports
Code
spam_found = 3
total = 12
print(f"{spam_found} of {total} messages were spam")
share = spam_found / total
print(f"That is {share:.0%} of the inbox")
Output
3 of 12 messages were spam
That is 25% of the inbox

A first look at errors (more in Lecture 2.3)

Read the last line of an error first. It names the problem.

What you typedWhat Python saysWhat it means
total = 12
print(totl)
NameError: name 'totl' is not defined
Typo in a name. Python only knows names you created. Check spelling.
print("hello)
SyntaxError: unterminated string literal (detected at line 1)
A quote or bracket was opened but not closed. Close it.
print("Total: " + 12)
TypeError: can only concatenate str (not "int") to str
Cannot glue text and a number with +. Use an f-string.
