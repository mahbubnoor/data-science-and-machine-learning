k-nearest neighbours in scikit-learn

  • n_neighbors is k
  • Small k: follows every single point (can overfit)
  • Large k: smoother, but may ignore real detail
  • Check several k on the test set... for now
Code
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
X, y = load_iris(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, random_state=1, stratify=y)
for k in [1, 3, 5, 15, 50]:
    knn = KNeighborsClassifier(n_neighbors=k)
    knn.fit(X_tr, y_tr)
    print(k, round(knn.score(X_te, y_te), 3))
Output

Decision boundaries: small k vs large k

Two sepal measurements, where the species overlap. Colours show the predicted class at every point: k = 1 draws jagged islands, k = 30 smooth regions.

Code
import numpy as np
X2 = X[:, 0:2]
xx, yy = np.meshgrid(np.linspace(4, 8.2, 300),
                     np.linspace(1.8, 4.6, 300))
grid = np.c_[xx.ravel(), yy.ravel()]
fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for ax, k in zip(axes, [1, 30]):
    m = KNeighborsClassifier(n_neighbors=k).fit(X2, y)
    zz = m.predict(grid).reshape(xx.shape)
    ax.contourf(xx, yy, zz, alpha=0.3, cmap="viridis")
    ax.scatter(X2[:, 0], X2[:, 1], c=y, s=12, cmap="viridis")
    ax.set_title(f"k = {k}")
    ax.set_xlabel("sepal length")
plt.show()

Train a tree and read its rules

max_depth=2: at most two questions per flower · export_text prints the learned rules · class 0 = setosa, 1 = versicolor, 2 = virginica · Nobody wrote these rules: the data did

Code
from sklearn.tree import DecisionTreeClassifier, export_text
names = ["sepal len", "sepal wid", "petal len", "petal wid"]
tree = DecisionTreeClassifier(max_depth=2, random_state=0)
tree.fit(X_tr, y_tr)
print(export_text(tree, feature_names=names))
print(round(tree.score(X_te, y_te), 3))

k-nearest neighbours or decision tree?

k-nearest neighbours

  • No real training: remembers all data
  • Slow to predict on big data
  • Needs features on similar scales
  • Hard to explain a single answer

Decision tree

  • Learns explicit if/else rules
  • Fast to predict
  • Scale of features does not matter
  • Deep trees overfit easily (Lecture 11)
