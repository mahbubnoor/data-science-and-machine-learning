Three kinds of mistakes

1

Syntax error

Python cannot read the code: a missing colon, bracket or quote. Nothing in the cell runs.

2

Runtime error

The code starts, then crashes at one line: a wrong name, a wrong type, a missing file.

3

Logic error

No message at all, but the answer is wrong. The hardest kind, because Python is happy.

A debugging routine you can always follow

1

Read the last line

Error type and message. Say in your own words what Python is complaining about.

2

Find the line

Go to the line number. Check that line and the one just above it.

3

Make one change

Change one thing only, then run again. Several changes at once hide what fixed it.

4

Still stuck?

Print the values involved, shrink the problem, then ask for help with the full error.

Answer: Bug hunt 1: find the mistake

Code
age = "20"
next_year = age + 1
print(next_year)
Output
TypeError: can only concatenate str (not "int") to str
  • "20" in quotes is text, not a number
  • Text + number is a TypeError
  • Fix: age = 20, or convert with int(age)
  • Data read from files and input() often arrives as text

Answer: Logic error: no message, wrong answer

Code
a = 70
b = 90
average = a + b / 2
print(average)
Output
115.0
  • Division happens before addition
  • So Python computes 70 + 45 = 115.0
  • Fix: (a + b) / 2
  • Always test with a case where you know the answer

Find logic errors by printing values

  • Goal: count the vowels in "banana" (expected 3)
  • The loop runs, but the answer is 1
  • Next step: print the values inside the loop
  • Look for the round where the value goes wrong
Code
word = "banana"
count = 0
for ch in word:
    if ch in "aeiou":
        count = 1
print(count)
Output
1
Md Mahbub E NoorLecture 2.3: Finding and fixing mistakesUniversity of Barishal15 / 26

Add a print inside the loop

  • Each round now shows ch and count
  • count never goes above 1
  • The line count = 1 sets instead of adds
  • Fix: count = count + 1, then delete the debug print
Code
word = "banana"
count = 0
for ch in word:
    if ch in "aeiou":
        count = 1
    print("ch =", ch, "count =", count)
print(count)

More tactics when you are stuck

1

Shrink it

Copy the failing part into a new cell with a tiny input. Small problems are easy to see.

2

Comment out

Put # before lines to switch them off, and find which line breaks things.

3

Restart and run all

Rules out the execution-order trap from Lecture 2.1 before you search any further.
