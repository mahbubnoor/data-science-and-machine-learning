Anatomy of an if statement

Code
marks = 72
if marks >= 50:
    print("You passed!")
print("Result checked")
Output
You passed!
Result checked
Keyword if starts a decision
Condition: a question that is True or False
Colon: the block starts on the next line
4 spaces: this line belongs to the if and runs only when True
No indent: outside the if, runs every time

An if inside an if (nesting)

  • Each level indents 4 more spaces
  • The inner question is asked only if the outer one is True
  • Use nesting when the second question only makes sense after the first
  • Otherwise and keeps the code flatter
Code
marks = 72
attendance = 60
if marks >= 50:
    if attendance >= 75:
        print("Pass")
    else:
        print("Pass marks, low attendance")
else:
    print("Fail")
Output
Pass marks, low attendance

match-case: one value, many fixed options

  • match compares one value with several patterns
  • | means or inside a case
  • case _: catches everything else, like else
  • number[:3] = first 3 characters (Lecture 3.2)
  • Needs Python 3.10+; Colab has it
Code
number = "01711111111"
match number[:3]:
    case "017" | "013":
        print("Grameenphone")
    case "019" | "014":
        print("Banglalink")
    case "018":
        print("Robi")
    case _:
        print("Unknown operator")
Output
Grameenphone

Solution 4: operator check

The else matters: without it, a wrong-length number would print INV and then also an operator name.

Code
number = "0151234567"
if len(number) != 11:
    print("INV")
else:
    match number[:3]:
        case "017" | "013":
            print("Grameenphone")
        case "019" | "014":
            print("Banglalink")
        case "015":
            print("Teletalk")
        case "016":
            print("Airtel")
        case "018":
            print("Robi")
        case _:
            print("INV")
Output
INV
