for or while?

for

  • You know what to walk through
  • Each item of a list, or a range of numbers
  • Ends by itself
  • Example: check every message

while

  • Repeat until something changes
  • You do not know how many rounds
  • You must update the condition yourself
  • Example: ask again until the password is right

break: stop the loop early

continue: skip to the next round

Nested loops: a loop inside a loop

  • The inner loop runs completely for each round of the outer loop
  • Here: every message is checked against every spam word
  • found resets to False for each new message
  • 3 messages x 2 words = 6 checks
Code
spam_words = ["free", "win"]
inbox = ["Win cash", "Class at 10",
         "Free gift"]
for msg in inbox:
    found = False
    for word in spam_words:
        if word in msg.lower():
            found = True
    print(found, msg)
Output
True Win cash
False Class at 10
True Free gift

Build it: a rule-based spam filter

Loops + decisions + a list of suspicious words: the filter from Lecture 1's demo, in real code.

Code
spam_words = ["free", "win", "prize", "cash"]
inbox = ["Win a free phone",
         "Class moved to room 305",
         "Claim your cash prize",
         "See you at the library"]
spam_count = 0
for msg in inbox:
    is_spam = False
    for word in spam_words:
        if word in msg.lower():
            is_spam = True
    if is_spam:
        spam_count = spam_count + 1
        print("SPAM  ", msg)
    else:
        print("OK    ", msg)
print(f"Flagged {spam_count} of {len(inbox)}")
Output
SPAM   Win a free phone
OK     Class moved to room 305
SPAM   Claim your cash prize
OK     See you at the library
Flagged 2 of 4

Solution 4: primes with a nested loop

A prime has no divisor between 2 and itself. break stops checking as soon as one divisor is found.

Code
N = 20
for n in range(2, N + 1):
    is_prime = True
    for d in range(2, n):
        if n % d == 0:
            is_prime = False
            break
    if is_prime:
        print(n, end=" ")
Output
2 3 5 7 11 13 17 19
