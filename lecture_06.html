Step 3: Words to numbers, in code

  • fit_transform on training data: learn the vocabulary, then count
  • transform on test data: count only, using that vocabulary
  • 7,680 different words learned
  • Never fit on the test set: that would peek at the exam
Code
from sklearn.feature_extraction.text import (
    CountVectorizer)

vec = CountVectorizer()
X_train_counts = vec.fit_transform(X_train)
X_test_counts = vec.transform(X_test)
print(X_train_counts.shape)

Step 3, up close: fit learns, transform reuses

  • fit reads the training messages and builds the vocabulary
  • transform counts words using that vocabulary only
  • "tomorrow" was never seen in training, so it is ignored
  • "a" is dropped: by default, one-letter words are skipped

Honest limits of our model

1

Old, foreign data

Mostly UK and Singapore messages from around 2011. New scam styles are unseen.

2

One small test

1,034 test messages, one random split. Another split gives a slightly different score.

3

Words only

It ignores word order, the sender and links. "FR33" tricks can still work.

4

Mistakes have costs

A real message lost in the spam folder can matter more than one spam let through.

The whole pipeline, start to finish

Everything from today in one cell. This short program is a complete, real machine learning project.

Code
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.metrics import accuracy_score

url = ("https://raw.githubusercontent.com/justmarkham/"
       "pycon-2016-tutorial/master/data/sms.tsv")
df = pd.read_csv(url, sep="\t", header=None,
                 names=["label", "message"]).drop_duplicates()
X_tr, X_te, y_tr, y_te = train_test_split(
    df["message"], df["label"], test_size=0.2,
    random_state=42, stratify=df["label"])
vec = CountVectorizer()
model = MultinomialNB().fit(vec.fit_transform(X_tr), y_tr)
pred = model.predict(vec.transform(X_te))
print(f"Accuracy: {accuracy_score(y_te, pred):.1%}")
Output
Accuracy: 98.2%

The model needs numbers. Use model.predict(vec.transform([...])).

X_bad = vec2.fit_transform(X_test)
model.predict(X_bad)
