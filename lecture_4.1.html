Default arguments: a value if none is given

How arguments are passed: names point to objects

  • A variable is a name that points to an object
  • Passing an argument does not copy the object
  • The parameter becomes a second name for the same object
  • Python's rule is called pass by object reference (or pass by assignment)
  • It is neither classic call by value nor call by reference

Changing a list inside a function changes it outside

  • lst.append(100) changes the list object itself
  • nums names that same object
  • So the caller sees the change
  • Lists and dictionaries are mutable: they can be changed
Code
def add_item(lst):
    lst.append(100)

nums = [10, 20, 30]
add_item(nums)
print(nums)
Output
[10, 20, 30, 100]

But reassigning inside a function does not

  • lst = [99] points the local name at a new list
  • The caller's name still points to the old list
  • Under true call by reference, nums would now be [99]
  • So Python is not call by reference
Code
def replace(lst):
    lst = [99]
    print("inside: ", lst)

nums = [10, 20, 30]
replace(nums)
print("outside:", nums)
Output
inside:  [99]
outside: [10, 20, 30]

Numbers and strings can only be replaced

  • Integers and strings are immutable: no operation changes them
  • n = n + 1 makes a new object and moves the local name
  • The caller's x is untouched
  • To get a new value out, return it: x = add_one(x)
Code
def add_one(n):
    n = n + 1
    return n

x = 10
add_one(x)
print(x)
x = add_one(x)
print(x)
Output
10

Solution: evens

Build the answer in a list, return it at the end. The caller decides whether to print it.

Code
def evens(n):
    result = []
    for i in range(1, n + 1):
        if i % 2 == 0:
            result.append(i)
    return result

print(evens(10))

Solutions: gcd and lcm

lcm reuses gcd: functions calling functions is how bigger programs are built.

Code
def gcd(a, b):
    result = 1
    for i in range(1, min(a, b) + 1):
        if a % i == 0 and b % i == 0:
            result = i
    return result

def lcm(a, b):
    return a * b // gcd(a, b)

print(gcd(8, 12), gcd(86, 44), lcm(8, 12))
Output
4 2 24

Solutions: mex and second_largest

while m in lst keeps counting up until it finds a number that is missing.

Code
def mex(lst):
    m = 0
    while m in lst:
        m = m + 1
    return m

def second_largest(lst):
    largest = max(lst)
    others = []
    for x in lst:
        if x != largest:
            others.append(x)
    return max(others)

print(mex([2, 1, 4, 0, 5]), mex([2, 1, 4, 0, 5, 3]))
print(second_largest([4, 9, 2, 9, 7]))
Output
3 6
7

return ends the function at once, so an invalid number can never also print an operator name.

def find_operator(number):
    if len(number) != 11:
        return "INV"
    match number[:3]:
        case "017" | "013": return "Grameenphone"
        case "014" | "019": return "Banglalink"
        case "015": return "Teletalk"
        case "016": return "Airtel"
        case "018": return "Robi"
        case _: return "INV"

print(find_operator("01411111111"))
print(find_operator("0131234567890"))

Banglalink
INV
