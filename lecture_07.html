Mean and median: two kinds of average

  • mean() adds everything and divides by the count
  • median() is the middle value after sorting
  • One extreme value pulls the mean, not the median
  • Real data often has extremes: report both
Code
import pandas as pd
marks = pd.Series([55, 62, 68, 70, 71, 74, 78, 99])
print(marks.mean())
print(marks.median())
marks2 = pd.Series([55, 62, 68, 70, 71, 74, 78, 300])
print(marks2.mean())
print(marks2.median())
Output
72.125
70.5
97.25
70.5

describe(): the whole summary at once

  • count, mean, standard deviation (std)
  • min and max: the range
  • 25%, 50%, 75%: quartiles (50% = median)
  • pandas std() divides by count - 1, so 2.14, not 2
Code
values = pd.Series([2, 4, 4, 4, 5, 5, 7, 9])
print(values.std().round(2))
print(values.describe().round(2))

Histogram: the shape of one column

A histogram groups values into bins and counts each bin. Spam and normal messages have very different length shapes.

Code
import matplotlib.pyplot as plt
df = pd.read_csv("sms.tsv", sep="\t", header=None,
                 names=["label", "message"])
df["length"] = df["message"].str.len()
ham = df[df["label"] == "ham"]["length"]
spam = df[df["label"] == "spam"]["length"]
plt.hist(ham, bins=40, alpha=0.6, label="ham")
plt.hist(spam, bins=40, alpha=0.6, label="spam")
plt.xlabel("message length (characters)")
plt.ylabel("number of messages")
plt.legend()
plt.show()

Correlation: how strongly two columns move together

Correlation r runs from -1 to +1. Close to +1: rise together. Close to -1: one rises as the other falls. Near 0: no straight-line pattern.

Code
import numpy as np
rng = np.random.default_rng(0)
x = rng.uniform(0, 10, 60)
ys = {"positive": 2 * x + rng.normal(0, 2, 60),
      "none": rng.normal(10, 4, 60),
      "negative": -2 * x + rng.normal(0, 2, 60)}
fig, axes = plt.subplots(1, 3, figsize=(10, 3))
for ax, (name, y) in zip(axes, ys.items()):
    r = np.corrcoef(x, y)[0, 1]
    ax.scatter(x, y, s=12)
    ax.set_title(f"{name}: r = {r:.2f}")
plt.show()

Correlation is not causation

1

Ice cream and drowning

Both rise in hot weather. Ice cream does not cause drowning; heat drives both.

2

Hidden third factor

A correlation can come from something you did not measure. Ask: what else could explain it?

3

Why it matters for ML

Models use correlations to predict. Prediction is useful, but it does not prove one thing causes another.

Common mistakes with charts and statistics

Read the last line of an error first. It names the problem.

What you typedWhat Python saysWhat it means
plt.scatter([1, 2, 3], [4, 5])
ValueError: x and y must be the same size
x and y must have the same number of values.
print(df["label"].mean())
TypeError: Cannot perform reduction 'mean' with string dtype
You cannot average text. Use value_counts() for categories.
plt.hist(df["lenght"])
KeyError: 'lenght'
Typo in the column name. Check df.columns.
