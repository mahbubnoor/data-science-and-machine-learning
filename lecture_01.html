What is data science?

Using data to answer questions and make better decisions.

  • Math & statistics: tell a real pattern from luck
  • Coding: handle data too big for a spreadsheet
  • Domain knowledge: ask questions that matter

Data science lives where all three overlap.

What is data?

Most data science starts with a table. Here are four text messages, described as data.

messagelengthcontains "free"has a numberlabel
Claim your FREE gift now24yesnospam
Class moved to room 30523noyesham
Free entry: text WIN to 8008629yesyesspam
Ok, see you at the library26nonoham
One row = one example

a single message, patient or sale

One column = one feature

a measured property, used as input (X)

Label column = the answer

what we want to predict (y)

A model learns how the feature columns relate to the label, then predicts the label for new rows. In Lecture 5 this table has 5,572 rows; in Lecture 6 we call the features X and the label y.

The data science lifecycle

1Ask
Will the river flood this week?
➜
2Collect
River levels and rainfall
➜
3Clean
Fill missing sensor readings
➜
4Explore
Plot rain vs. river level
➜
5Model
Forecast tomorrow's level
➜
6Share
Early alerts to farmers

A loop, not a line: exploring often sends you back to ask a better question. Modeling is one step of six.
