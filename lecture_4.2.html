Recap from 4.1: a spam check as a function

  • def defines a function: a named, reusable block
  • message is the input (a parameter)
  • return hands back the answer and stops
  • Call it by name: is_spam("...")
Code
def is_spam(message):
    text = message.lower()
    for word in ["free", "win", "prize"]:
        if word in text:
            return True
    return False

print(is_spam("Win a phone today"))
print(is_spam("See you at 5"))
Output
True
False

Dictionaries: look up a value by name

  • Curly braces: {key: value}
  • Look up with counts["win"]
  • Add or change: counts["prize"] = 1
  • Like a word book: word → how many times we saw it
Code
counts = {"win": 2, "free": 1}
print(counts["win"])
counts["prize"] = 1
counts["win"] = counts["win"] + 1
print(counts)
Output
2
{'win': 3, 'free': 1, 'prize': 1}

Count every word in many messages

counts.get(word, 0) means: the current count, or 0 if we have never seen this word.

Code
def count_words(messages):
    counts = {}
    for msg in messages:
        for word in msg.lower().split():
            counts[word] = counts.get(word, 0) + 1
    return counts

spam_msgs = ["Win a free prize", "Free cash win now",
             "Claim your free gift"]
spam_counts = count_words(spam_msgs)
print(spam_counts)
Output
{'win': 2, 'a': 1, 'free': 3, 'prize': 1, 'cash': 1,
'now': 1, 'claim': 1, 'your': 1, 'gift': 1}

A spam score learned from examples

Add a point for each word seen in spam, subtract one for each word seen in normal messages.

Code
def spam_score(message):
    score = 0
    for word in message.lower().split():
        score = score + spam_counts.get(word, 0)
        score = score - ham_counts.get(word, 0)
    return score

for msg in ["Free prize for you", "See you in class",
            "Claim cash now"]:
    print(spam_score(msg), msg)
Output
2 Free prize for you
-4 See you in class
2 Claim cash now

Common mistakes with functions and dictionaries

Read the last line of an error first. It names the problem.

What you typedWhat Python saysWhat it means
print(spam_counts["hello"])
KeyError: 'hello'
The key does not exist. Use spam_counts.get("hello", 0).
def double(x):
    x * 2
print(double(4))
None
No error, but None: the function forgot to return.
print(spam_score())
TypeError: spam_score() missing 1 required positional argument: 'message'
The function needs an input. Pass a message.
