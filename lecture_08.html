Machine learning in one sentence

1

Examples in

We give the computer many examples: inputs (features) and, often, the right answers (labels).

2

Pattern learned

An algorithm finds a rule, called a model, that maps inputs to answers.

3

New answers out

The model predicts answers for inputs it has never seen. That is the whole point.

Supervised or unsupervised?

Supervised (labels given)

  • Every example has the right answer
  • Goal: predict the answer for new inputs
  • Spam filter, price prediction, diagnosis
  • Lectures 9 to 12

Unsupervised (no labels)

  • Only inputs, no answers
  • Goal: find structure, such as groups
  • Customer segments, topic grouping
  • Lecture 13

Look first: can the classes be told apart?

Two petal measurements already separate the species well. Machine learning finds such patterns automatically, in many dimensions.

Code
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
iris = load_iris(as_frame=True)
X = iris.data
y = iris.target
for k, name in enumerate(iris.target_names):
    part = X[y == k]
    plt.scatter(part["petal length (cm)"],
                part["petal width (cm)"], label=name)
plt.xlabel("petal length (cm)")
plt.ylabel("petal width (cm)")
plt.legend()
plt.show()

The same pattern for every model

  • Split first, with the same function as Lecture 6
  • fit learns from training data
  • score reports accuracy on test data
  • Swap the model; the code stays the same
Code
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.naive_bayes import GaussianNB
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)
for model in [KNeighborsClassifier(),
              DecisionTreeClassifier(random_state=0),
              GaussianNB()]:
    model.fit(X_tr, y_tr)
    acc = model.score(X_te, y_te)
    print(type(model).__name__, round(acc, 3))
Output
KNeighborsClassifier 0.978
DecisionTreeClassifier 0.978
GaussianNB 0.911

Output

0.933
  • On training data it just finds each flower itself
  • That is memorising, not learning
  • Only the test score shows real skill
  • Never report training accuracy as your result

Generalisation: the real goal

1

Memorising

Learning the exact exam questions. Perfect on those, lost on new ones.

2

Generalising

Understanding the patterns, so new questions can be answered too.

3

How we check

Keep a test set the model never sees, and judge it only there.
