What to notice

  • count = 1 sets the value; count + 1 calculates and throws the answer away. Only count = count + 1 (or +=) adds.
  • Python does / before +, exactly as in maths. Brackets change the order.
  • Logic errors are found by testing with an example whose answer you already know.

What to notice

  • [ ] = never run in this session; [3] = the third cell run. The numbers show the real order.
  • An orange dot means the cell was edited after it last ran: the screen and the memory disagree.
  • Restart and run all rebuilds memory from the top, exactly as a fresh reader (or your teacher) would.
