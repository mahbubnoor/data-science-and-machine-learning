Meet the dataset: SMS Spam Collection

1

5,572 real messages

Real SMS messages, each labeled by people as spam or ham (normal).

2

Where from

Published in 2011 by Almeida and Hidalgo, and shared on the UCI Machine Learning Repository.

3

Its limits

Load the data in one line

  • import pandas as pd loads the library, nicknamed pd
  • read_csv reads a table from a file or web link
  • sep="\t": columns are separated by tabs
  • df (DataFrame) is a table; .shape is (rows, columns)
Code
import pandas as pd

url = ("https://raw.githubusercontent.com/"
       "justmarkham/pycon-2016-tutorial/"
       "master/data/sms.tsv")
df = pd.read_csv(url, sep="\t", header=None,
                 names=["label", "message"])
print(df.shape)
Output
(5572, 2)

Spam messages are longer

  • .str.len() measures every message at once
  • A new column: df["length"]
  • groupby("label") splits the table by label
  • Spam averages about twice the length of ham
Code
df["length"] = df["message"].str.len()
avg = df.groupby("label")["length"].mean()
print(avg.round(1))

Clean out duplicate messages

  • duplicated() marks rows seen before
  • 403 messages appear more than once
  • Spammers send the same text to many people
  • Duplicates could leak into both training and testing, so we drop them
Code
print(df.duplicated().sum())
df = df.drop_duplicates()
print(df.shape)
print(df["label"].value_counts())

Test a rule on real data

  • str.contains("free") checks every message at once
  • Mean of True/False = the share that is True
  • "free" appears in far more spam than ham
  • Yet 3 in 4 spam messages never say "free"
Code
text = df["message"].str.lower()
df["has_free"] = text.str.contains("free")
share = df.groupby("label")["has_free"].mean()
print(share.round(3))
Output
label
ham     0.014
spam    0.259

Common pandas mistakes

Read the last line of an error first. It names the problem.

What you typedWhat Python saysWhat it means
print(df["Label"])
KeyError: 'Label'
Column names are case-sensitive. The column is "label".
print(df.lenght)
AttributeError: 'DataFrame' object has no attribute 'lenght'
Typo in a name. Check spelling, or print(df.columns).
print(df["message"].lower())
AttributeError: 'Series' object has no attribute 'lower'
A column is not a single string. Use .str.lower() for text columns.
