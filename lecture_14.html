Where unfairness comes from

1

The data

The labels

3

The measurement

A simple, essential check: performance per group

cross_val_predict gives an honest prediction for every row · Then compare accuracy group by group · Large gaps need explaining before any use · students.csv is invented: this shows the method only

Code
import pandas as pd
from sklearn.compose import make_column_transformer
from sklearn.impute import SimpleImputer
from sklearn.model_selection import cross_val_predict
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import OneHotEncoder
from sklearn.preprocessing import StandardScaler
st = pd.read_csv("students.csv")
num = ["hours", "attendance", "prior_gpa"]
prep = make_column_transformer(
    (make_pipeline(SimpleImputer(strategy="median"),
                   StandardScaler()), num),
    (OneHotEncoder(), ["dept"]))
model = make_pipeline(prep, KNeighborsClassifier())
X = st[num + ["dept"]]
st["pred"] = cross_val_predict(model, X, st["passed"], cv=5)
st["correct"] = st["pred"] == st["passed"]
print(st.groupby("dept")["correct"].mean().round(3))

Privacy and consent

1

Collect only what you need

If a name or phone number does not help the question, do not collect it.

2

Remove identifiers

Delete names, numbers and addresses before analysis. Your SMS homework already did this.

3

Ask permission

People should know and agree when their data is used. Store it safely and delete it when done.

A first look at neural networks

1

A neuron

Multiplies each input by a weight, adds them up with a bias, and passes the result through a simple function.

2

Layers

Many neurons side by side form a layer; layers stacked together form a network.

3

Learning

Training adjusts the weights a little at a time to reduce the error, like the line search in Lecture 9.

A small neural network on the digits

MLPClassifier: a multi-layer perceptron · One hidden layer of 64 neurons · Same fit / score pattern as every model · Compare with k-NN from Practice 3 on the same split

Code
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neural_network import MLPClassifier
X, y = load_digits(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.25, random_state=0, stratify=y)
knn = KNeighborsClassifier(n_neighbors=1)
net = MLPClassifier(hidden_layer_sizes=(64,),
                    max_iter=1000, random_state=0)
for name, m in [("kNN k=1", knn), ("neural net", net)]:
    pipe = make_pipeline(StandardScaler(), m)
    pipe.fit(X_tr, y_tr)
    print(name, round(pipe.score(X_te, y_te), 3))
Output

neural net 0.973
