What is a program?

1

Instructions

A program is a list of instructions, written in a language the computer can follow.

2

Top to bottom

Python reads your code one line at a time, from the top, and does exactly what each line says.

3

Exact, not smart

A missing bracket or a misspelled name stops it. Precision is a skill you will build.

Execution order: the notebook trap

Python remembers what has RUN, not what is written on screen. Cell A: x = 5. Cell B: print(x * 2).

Code
# Cell A
x = 5

# Cell B
print(x * 2)
stepwhat you dox in memoryB prints
1Run A5(nothing)
2Run B510
3Edit A to x = 7, do not run5(nothing)
4Run B510 (surprise!)
5Run A7(nothing)
6Run B714

Next row: arrow key or the ▶ button. Predict it first!

The cure: restart and run all

Restarting wipes Python's memory. Running all then rebuilds it from the top, in order, exactly as written.

ToolWhere to find it
Jupyter NotebookKernel menu > Restart Kernel and Run All Cells
Google ColabRuntime menu > Restart session and run all (older versions say Restart runtime)
WhenBefore every homework submission, and whenever results look impossible
Why it mattersIf a notebook only works when run in some special order, it does not really work
